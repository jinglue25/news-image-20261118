A one-image summary of the world's news on Wednesday 18 November 2026 built for make.fun's news-image-20261118 bounty.

## Run it

Requires Node.js 22 with support for running `.ts` files directly.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the bundled `entry.png` to the output directory. To regenerate the image, run `python3 draw.py` with Pillow installed and DejaVu fonts available in `/usr/share/fonts/truetype/dejavu`.
